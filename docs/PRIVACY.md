# 数据与隐私

## 本地输入

Computer History 是上游数据源。本应用只读其事件与记忆文件，不开启记录、不更改观察设置、不改写或删除上游文件。也可读取本应用的导出包。目录授权通过系统文件选择器完成。

本地事件文件格式可能变化。未知字段在原始导出中保留，损坏行、无法定位时间的行和活动文件的不完整尾行会报告或跳过。条数代表事件，不能据此推断任务次数、耗时或业务完成。

## 云端分析

用户点击「发现新候选」后，应用整理有限长度的事件文本和摘要，经 Codex CLI 发送分析。输入会明确标注覆盖和截取情况；它可能含有私人内容。截取和排除工作台自身事件用于控制长度及避免反馈循环，不等于敏感信息筛选。

源文本被视为不可信数据，模型只输出候选 JSON；引用须来自当前输入，候选不能执行工作。使用 ChatGPT 订阅登录并消耗相应额度，登录或额度失败时停止，没有 API Key 计费回退。

## 临时认证

随附运行器在一次性目录里复制 ChatGPT 认证，使用独立 CODEX_HOME；不复制个人配置、hooks、插件、个人全局说明和 MCP OAuth。shell 工具与网页搜索关闭，运行采用 read-only sandbox。这个 sandbox 不是完全文件系统隔离，不应将该机制当作安全虚拟机。

正常退出、超时和可捕获的 SIGINT/SIGTERM/SIGHUP 会停止子进程组并删除临时认证。SIGKILL、系统崩溃或断电可能留下私有临时目录，可在应用数据目录中核查 `.codex-home-*`。认证、工作记录和分析文件不应上传 GitHub。

如果用户配置了外部隔离运行器，以该入口的实际边界为准。当前机器存在的本地隔离入口不会被本项目修改。

## 保存与删除

本地应用数据目录包括导出、模型输入、运行回执、结果及复用反馈。它们独立于上游生命周期，应用不会自动删除；用户可通过「打开数据目录」自行管理。

源目录只读、导出成功、模型生成草稿、用户采用和实际复用有效分别记录，互不替代。
